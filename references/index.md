# 34个主题的使用入口

从当前最具体的一件事选一至两个主题。每个主题先给情境、区分、材料机制、问题、选项和限制，再附可操作的建议。

Python入口：`python scripts/consult.py "你的具体问题" --top-k 3`。没有Python时，直接打开下面的Markdown主题文件。

| [职业收入的薄弱处](scenarios/work-risk.md) | 25 | 高工资是一段时间的结果，持续拿到收入还依赖客户、技术、城市和组织。先查清自己究竟押在什么上面。 |
| [能带走的本事](scenarios/work-skill.md) | 25 | 不要把熟悉公司当成熟悉市场。把解决问题、交付和判断的本事，练成离开原单位也能被检验的成果。 |
| [求职与转岗的证据](scenarios/work-move.md) | 25 | 换一个岗位要增加实际选择，不能只换一个让人安心的说法。条件、证据、退出安排都要先落纸。 |

| [现金要能在需要时到手](scenarios/money-cash.md) | 20 | 先检查付款时点、可用范围和替代通道。钱在账上与钱能按时付出去，往往是两回事。 |
| [收入不能只看总额](scenarios/money-income.md) | 20 | 拆开收入的来源、条件与到账节奏，找出同一件事会让哪些钱一起停下。 |
| [长期承诺会压缩退路](scenarios/money-commitment.md) | 20 | 大额承诺最容易藏起的是未来的付款义务和中途改变的代价。先问停下怎么办，再决定开始。 |

| [别让一处失败拖走全家](scenarios/money-business.md) | 20 | 经营、亲友合作和家庭资金之间的连接，需要逐条看清。关系信任不能省略对责任和去向的核对。 |
| [养老要有可持续的安排](scenarios/money-retirement.md) | 20 | 把自己的生活、住房和照护需求写在前面，再谈对子女的支持与未来愿景。 |

| [亲密与家庭](scenarios/family.md) | 6 | 很多家庭矛盾并不缺道理，缺的是钱由谁决定、事情由谁负责、付出到哪里为止。把这些说到具体安排，才有改变的可能。 |
| [家庭运转与职业保全](scenarios/family-capacity.md) | 25 | 先看家庭的时间、照护和收入怎样相互牵制，再决定谁调整工作。能持续运转，才有余力谈发展。 |
| [伴侣合作与关系风险](scenarios/family-partner.md) | 25 | 承诺是否可靠，要看它如何落到共同决定、资源安排和冲突处理上。关系问题不能全靠一个人多付出。 |
| [代际支持与家庭边界](scenarios/family-generations.md) | 25 | 支持可以帮助起步，也可能变成几代人互相透支。把用途、权限和承接能力分别说清楚。 |
| [陪孩子长大](scenarios/education.md) | 7 | 升学只是教育的一部分。钱和时间有限时，每加一个安排，都要说清要解决什么、挤掉了什么，以及孩子最终能独立做什么。 |
| [孩子的生活与社会能力](scenarios/family-competence.md) | 25 | 会考试不等于能独立生活。把被成人包办的真实任务逐步交还，让能力在具体结果里出现。 |
| [教育投入与成本约束](scenarios/family-spending.md) | 25 | 资源有限时，教育选择必须说明解决什么、由谁执行、用什么证据续投，而不是跟着焦虑购买。 |
| [升学分流与路线核验](scenarios/family-routes.md) | 25 | 专业、学校和国家都是条件组合。先核实门槛、课程和退路，才能比较哪条路适合这个孩子。 |
| [从校园到工作](scenarios/family-transition.md) | 25 | 走出校园后，别人需要的是能使用的结果。把学习、求职和真实任务接起来，减少毕业时才补课的代价。 |
| [中产二代的承接能力](scenarios/family-inheritance.md) | 25 | 父母能提供启动条件，却不能把能力和判断直接过户。帮助下一代承接资源，要让他们参与决定、实践和修正。 |
| [比较与处境](scenarios/comparison.md) | 6 | 别人的消费、头衔和热闹，只展示了一部分。不要拿自己完整的生活，去追一张看不见成本的成绩单。先核实条件，再决定跟不跟。 |
