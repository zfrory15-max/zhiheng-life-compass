# 设计与来源

## 目标

知衡·人生解局帮助使用者把职业、家庭、教育、财富压力、社会比较和自我价值问题，整理成有现实条件、有选择空间、可以尝试和复盘的行动。

“中产”在这里描述一种处境：可能同时承担工作、住房、育儿、养老和发展期待。它不是收入门槛，也不用于推断一个人的性格、能力、家庭形式或价值排序。

## 技能如何工作

这个仓库提供的是可供智能体阅读的说明、知识卡与检索工具，没有训练、微调或改变模型参数。

核心流程是：

1. 明确本次问题与使用者希望获得的帮助。
2. 只澄清会改变判断的缺失信息。
3. 选择一至两个主要主题，阅读相关卡片及其限制。
4. 区分用户陈述、课程观点、待核实信息和本次推论。
5. 比较选择的代价与条件，形成小范围行动或继续观察的安排。

智能体应保留使用者的选择权。分析框架不能把个人困难全部解释为不够努力，也不能把社会环境写成无法改变的命运。

## 公开版的资料范围

v2公开版包含34个细分主题判断指南、699条行动建议、102条材料机制，并保留原来的39张基础知识卡。主题从职业收入的薄弱处、可迁移能力、组织协作、现金到账、长期承诺，到照护接班、教育投入、升学路线、资源承接与压力下的判断。

699条来自已经审校的网页建议，每条都有具体步骤、模板、产出与检查信号。新增主题指南经过回读原文上下文后整理，为这些步骤补充适用情境、关键区分、澄清问题、选项代价与限制。三条机制并不代表同等强度的实证证据。

课程主要支持问题机制与看待问题的角度。具体步骤、练习期限和数量通常是编者将机制应用到场景后的设计，不应声称原课提供了同一操作方案。适用条件或专业事实缺失时，缩小结论并另行核实。

原始整理工作参考了七份课程转录资料。来源名称与标识见 [来源登记](../references/source-register.md)。

公开版不分发：

- 原始 DOCX、录音或完整转录。
- 逐字引文及用于核对原句的原文片段。
- 完整原文章节目录、个人文件路径或原文文件链接。

因此，“有来源”在这个包里指**能够知道概括卡依据哪项已登记材料整理**。卡片可保留原章节标题、段落、字符范围和支持范围，作为定位元数据；它们不表示读者能在包内逐字回查。指向来源登记的链接也不是原文或外部证据链接。需要核对具体说法、原句或上下文时，应另行取得原材料。

## 怎样理解一张卡

卡片中的课程观点是对材料的概括；适用条件、澄清问题、行动练习和限制用于约束实际调用。

行动练习是技能设计，不应包装为讲师原话、固定疗法或经过实验验证的干预。几天、几次、几个步骤等安排，是为了让尝试便于执行与复盘，不是效果保证。

资料和定位信息供内部核查，日常咨询回答默认不展示出处。用户明确要求溯源时，只能使用实际存在并已读取的卡片标识和来源登记；可以展示已登记的章节、段落和字符范围，并说明本包不能据此核对原句；不得编造新的定位信息、原文页码、音视频时间或带引号的“原话”。使用者另行提供原材料后，才可进一步核验。

## 资料的局限

课程转录包含口语表达、转写错误、个案、时代背景和讲师判断。它们不自动等于学术共识、医学证据或现行政策。

整理时采用情境、角色、资源和个人期待等分析视角，并限制以下内容的使用：

- 不把性别、阶层、代际或学校标签当作对个人的结论。
- 不把情绪变化、关系冲突或学习困难当作人格或疾病诊断。
- 不采纳通过欺骗、羞辱、诱导内疚来控制他人的行动策略。
- 不直接沿用资产比例、收益预测、法律后果、医疗结论和宏观预测。

当两种观点看似冲突，应先看适用条件与讨论对象；公开卡不足以解释时，明确承认缺口，而不是编造不存在的上下文。

## 工具与个人信息

新入口scripts/consult.py使用Python标准库，从34个主题分块检索699条行动，并同时返回相关主题的适用条件、机制与限制。原scripts/search.py保留39张基础卡检索。文字匹配分数不是正确率，也不是决策成功概率。无需Python时沿Markdown主题目录阅读。

技能默认不要求建立个人档案，不把敏感对话追加到知识卡。具体宿主如何调用模型、保留对话或处理文件，仍取决于宿主设置与服务规则；本仓库不替宿主作隐私承诺。

## 与完整个人版的区别

完整个人版保留了用于内部阅读、定位和回查的原文资料，曾在 Codex 中实际调用。本公开版缩小了资料范围，也改变了检索对象。

两个版本不能直接混合目录，也不能共用“原文可回查”的说明。公开版的 CLI、迁移和行为验证状态以 [验证记录](验证记录.md) 为准。
