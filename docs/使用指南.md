# 使用指南

## 先说清这一次想解决什么

不必提交完整人生档案。通常提供以下信息中的相关部分就够了：

- 眼前的一件事：例如是否转岗、怎样分配照护、如何减少比较焦虑。
- 希望得到的帮助：倾听、解释、比较方案、沟通话术或一周行动。
- 已知约束：可用时间、必要支出、家庭责任、决定时限。
- 不愿接受的代价：例如不借贷、不立即辞职、不挤占孩子睡眠。

不需要提供身份证号、账号、精确住址或单位内部资料。财务状况可以用大致区间表达。

## 可以直接复制的请求

### 信息还不清楚时

> 请使用知衡·人生解局。我工作进入瓶颈，也承担家庭照护。我想判断是否应该转型。先帮我找到会改变判断的关键信息，每轮最多问三个实际问题。

### 已有约束时

> 请使用知衡·人生解局。我做行政多年，想了解项目协调岗位。每周可用六小时，家庭希望先保留收入，我不接受借贷。请帮我设计一周的低成本验证，并说明怎样判断是否值得继续。

### 家庭协商时

> 请使用知衡·人生解局。我们都愿意重新分配照护责任。我不能再增加时间，伴侣可以多承担周末半天，新增预算有限。请先指出安排中还缺什么，再给我们一段可协商的话术。

### 只需要倾听时

> 请使用知衡·人生解局。我最近被同龄人的升职消息影响，感到自己落后了。先听我说，帮我分清事实、推测和我真正看重的东西，暂时不要列行动清单。

## 正常回答应是什么样

信息不足时，回答应简短承接你的处境，并提出会影响判断的问题。它不应靠想象补齐收入、性别、婚姻状态或对方的动机。

信息足够时，回答通常包括：

1. 根据你已提供的信息，说明目前怎样理解问题。
2. 比较确实可行的选择，说明收益、代价、条件和可逆性。
3. 给出一至三个小行动，约定观察什么、何时复盘和何时调整。
4. 自然说清还不能确定的地方，以及什么条件会改变建议。

回答默认不列课程出处、卡片编号、文件名和“来源／依据”栏目。内部仍会核对资料，你主动问“为什么这样判断”或“出处在哪里”时才展开；涉及现行专业事实仍须核实并遵守宿主的必要引用规则。

它会用日常语言和自然段落回应具体处境，避免每次都套用报告格式、空泛安慰或布置作业。这些表达规则不是让智能体冒充真人或持证咨询师。

你可以随时纠正假设，要求缩短回答，或说“我现在只想讨论情绪，不作决定”。七天行动是可调整的默认形式，不是必须完成的作业。

## 在 Codex 中安装

下载Skill v2安装包，将其中的技能文件夹放到 `~/.agents/skills/zhiheng-life-compass/`，确保该目录下直接存在 `SKILL.md`。安装时不要多嵌套一层同名目录。

如果该位置已有完整版或其他版本：

1. 先将原目录完整备份到技能扫描目录之外。
2. 单独安装本公开版，不合并两个版本的 `data/`、`references/` 或脚本。
3. 在新对话中确认调用的是公开版，再保留或恢复原版本。

可通过技能选择器选择“知衡·人生解局”，或在支持显式技能调用的界面中使用 `$zhiheng-life-compass`。宿主没有识别到技能时，先检查路径与 `SKILL.md`，再按该宿主的加载方式刷新或新建对话。

## 在 WorkBuddy 中导入

发布包为 `zhiheng-life-compass-public-v2.0.0.zip`，可在仓库目录执行 `python scripts/build_release.py` 生成。在支持 ZIP 技能导入的版本中，使用其导入入口选择该文件，并确认导入结果包含技能说明和附带资源。

本公开包未在 WorkBuddy 中实测，不能据此保证每个版本的目录规则、工具权限或技能触发方式相同。若导入校验失败，应保留错误信息，再按当前版本的说明核对；不要反复叠加安装不同结构的包。

导入后可先测试：

> 请使用知衡·人生解局，说明你能帮助我分析哪些问题，以及你是否能提供课程原话。

正确的公开版说明应明确：可以使用概括知识卡，包内没有可核对的课程全文和逐字引文。

## 有无 Python 都可以用

有 Python 3.10+ 时，在技能目录运行：

```bash
python scripts/consult.py "家庭照护接班，如何保留工作" --top-k 3
python scripts/consult.py "为教育投入挤占养老存款" --top-k 3
python scripts/consult.py --topic money-care "照护者休息"
python scripts/consult.py --id M141
```

检索范围是699条公开行动及34个主题的条件与机制。读到结果后，要将topic_context和results一起使用，不能只取标题；数字、期限和步骤按用户约束调整。原有39张基础卡仍可用scripts/search.py检索。

没有 Python 时，沿 [SKILL.md](../SKILL.md) 的主题入口阅读 Markdown。宿主无需为了使用本技能自动安装软件。

## 遇到这些情况时

- **需要课程原话**：本包不能核对原句。已登记的章节、段落和字符范围仅提供定位线索；提供原材料后再核验，不应从摘要重造引文。
- **需要当前政策、医疗、法律或投资判断**：课程摘要不足以确认，应使用可靠的当前来源或适当专业支持。
- **遭遇暴力、威胁或急性危机**：先关注即时安全与现实支持，暂停普通关系修复和人生规划。
- **建议不符合你的目标**：直接指出“我更重视什么”“我不能承担什么”，让智能体重新比较。

技能不等于授权智能体替你联系他人、交易、提交资料或保存个人档案。需要这些操作时，应单独明确范围。
